# Барбарис Bot 🍒

Уютный Telegram бот для модерации чатов, RP-игр, экономики и браков. Полный аналог IrisBot с расширенным функционалом.

## Возможности

### 👮‍♂️ Модерация
- Приветствие новых участников
- Защита от спама и флуда
- Фильтр мата
- Блокировка ссылок
- Система предупреждений (варнов)
- Роли администраторов (владелец, главный админ, админ, модератор)

### 💎 Экономика
- Внутренняя валюта "барбариски"
- Начисление за активность в чате
- Топ богачей чата
- Премиум-подписка за барбариски

### 🎭 RP-команды
- Обнимашки, поцелуйчики, поглаживания
- 18+ команды для премиум-пользователей
- Случайные гифки к командам

### 💍 Система браков
- Подача заявок
- Подтверждение через кнопки
- Статистика брака
- Возможность развода

### 🎲 Гадалка
- Ответы на вопросы с вероятностью
- Разнообразные варианты ответов

## Установка на Railway

1. **Форкни этот репозиторий** на GitHub

2. **Создай бота в Telegram** через @BotFather и получи токен

3. **На Railway создай новый проект** из GitHub репозитория

4. **Добавь переменные окружения** в Railway:
   - `BOT_TOKEN` - токен твоего бота
   - `DATABASE_URL` - URL PostgreSQL базы данных (Railway предоставит автоматически)
   - `OWNER_ID` - твой Telegram ID (узнай у @userinfobot)
   - `TENOR_API_KEY` - (опционально) ключ для гифок

5. **Деплой!** Railway автоматически установит зависимости и запустит бота
